# Sort 新旧 Bandwidth 对照

单位：GB/s。以下为 standalone sort-core 的有效 BW，不是硬件计数器测到的 DRAM BW，
也不是集成补丁后的 `aten::sort` 端到端结果。

```text
有效 BW = 元素数 * (2 * key 字节数 + 8) / (GPU 核心耗时 us * 1000)
BW 变化 = (新 BW / 旧 BW - 1) * 100%
```

旧版本：[51acfc9](https://github.com/intel/torch-xpu-ops/commit/51acfc9f9d1d167f8f86cdd7e88868fd54c60a48)；
新版本：[7f24c79](https://github.com/intel/torch-xpu-ops/commit/7f24c79c09fb0ee8112773a15659e2d76a017feb)。
测量使用同一 Intel XPU、同一 icpx 2026.2 standalone SYCL 二进制，contiguous、最后一维升序、
int64 输出索引。两臂使用相同输入；原 Reformer `.pt` 文件只包含 metadata，未保存原始数值。
主表来自同一轮 84-case 初筛，每个 case 7 轮交错配对，每侧预热至少 5 ms device work。
GPU 耗时为逐轮 kernel-duration-sum 中位数的中位数；JIT、分配、输入恢复、poison 和正确性检查在计时外。
未用复测替换初测，变化百分比由未舍入的原始数值计算。

- †：至少一侧逐轮耗时 CV > 5%，数字有明显波动，不作为稳定收益承诺。
- ‡：int32 768x4096 的初筛异常，单独 15 轮配对复测未重现退化。
- 只有 int64/float64、行长 (2048,4096] 的 10 个 case 改变配置。
  其他控制组的表观变化不能归因为新 kernel 配置。
- 测量环境不保证 GPU 独占；未测量实际 DRAM BW、occupancy 或波动的具体来源。
